## Acceptance protocol to agree before bounded runs

| Gate | Required proof |
|---|---|
| Integrity | Same source/pipeline/model/parameters rerun cannot multiply equivalent records; source resolution and valid ranges for every derivative; concurrent/retry failure cases. |
| Playback | Source/time correct within agreed numeric tolerance; play beyond matched interval; replay/scrub plus Prev/Next and Gallery return. |
| Transcript | Highlight/follow, utterance/timestamp seek, manual scroll, selection refinement, overlay audit and original preservation in rendered UI. |
| Face | Owner-labeled short/sustained/occluded/multiple-person samples; grouping errors and counts; Learn/review/correct/retire with provenance. |
| Voice | Clean and poor audio, off-camera and no-match ground truth; report precision/recall/abstention by modality; face never substitutes for voice. |
| Corroboration | Independent source/time/confidence inputs visible and traceable; conflict/uncertainty examples; policy version recorded. |
| Retrieval | Exact phrase, Person-speaking, semantic subject, Person-appearance fixtures with relevant source/time results; phrase across turns and stale-index cases. |
| Legacy fragments | Every authoritative inventoried row/file classified in migration/quarantine/deletion-eligibility ledger; reconciled source/reference counts; zero unclassified. |
| Jobs | Persisted scope/progress/counts/failures reconcile; Pause/Retry/View, restart recovery and partial failure observed. |
| Regression | Gallery cards/query/filter/sort/scroll; modal navigation; Person filter; timeline resize/playhead/year-month-day precision; shared owner shell; I12 unchanged. |
| Safety | API and worker reject pre-acceptance archive jobs and off-manifest sources; unlock does not enqueue; no provider/source mutation. |
| Proof | Tests, screenshots, before/after counts, elapsed/GPU/CPU measurements, failed cases, rollback and residual risks; founder reviews evidence. |

No arbitrary numeric quality/timing thresholds are proposed as already accepted. Measure the approved hardware/corpus and agree thresholds before claiming acceptance. Accessibility must include keyboard-only selection and navigation, visible focus, labels, and non-color state cues. Privacy must keep evidence and owner judgments away from contributor-facing workflows.
