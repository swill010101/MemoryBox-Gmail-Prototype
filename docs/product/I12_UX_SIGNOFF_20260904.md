## Scope of this sign-off

This document captures the **material owner corrections** applied during FlightSim review and the **final accepted behavior** for Historian Capture product UI. Engineering/admin surfaces and internal identifiers are explicitly out of scope for product UI.

**Reference mockups** on branch `codex/historian-capture-reference-screens-20260829` @ `fe913a4` are **layout reference only** and are **not** the accepted product spec. The accepted UI is the shipped MB-dark implementation.

---

## Accepted navigation and chrome

| Requirement | Accepted behavior |
|-------------|-------------------|
| Entry | Review & Learn → Historian Capture (`/historian-capture/ui`) |
| Header | Canonical MemoryBox explore chrome; readable logo on dark background |
| Theme | MB dark surfaces throughout — no large white form panels |
| Internal IDs | HC-01, HC-02, etc. **not shown** in product UI |
| Engineering controls | No Tick, Poll inbound, stage IDs, or scheduler diagnostics in UI |

## Dashboard (Needs review / Kept / Rejected / Campaigns / Needs attention)

| Correction | Accepted behavior |
|------------|-------------------|
| White cards on dark page | All cards, panels, sides use `#1a2230` dark surfaces with light text |
| Slow load | Lazy people load; optimized item list query |
| Rejected filter empty after verdict | Tab lists refresh after save |
| System messages too small / bottom | Inline flash messages beside the pressed button |

---

## New campaign form

| Correction | Accepted behavior |
|------------|-------------------|
| Person picker | Dropdown with search at top (alphabetical list) |
| Email autofill | On person select, fetch `/people/{id}/profile` for first email contact |
| Starter questions | “Add starter questions” button loads `/historian-capture/starter-questions` |
| Follow-up duration | **Days** input; default **7 days** |
| Questions input | One question per line (newline-separated) |
| Password manager interference | `autocomplete="off"` + `data-1p-ignore` on title/email fields |
| Draft vs running clarity | Status badges (Draft / In progress); Edit draft + Start campaign on drafts |

---

## Campaign detail dashboard

| Correction | Accepted behavior |
|------------|-------------------|
| No campaign review screen | Full dashboard: metrics, settings, people, question progress, replies |
| Back navigation | Breadcrumb: Historian Capture › Campaigns › title |
| Delete | Confirmation modal (Stories/Artifacts pattern) |
| Advance campaign | “Send next question now” — enabled only when running, not waiting for reply, has pending question |
| Delivery log | Expandable per-question delivery details |

---

## Review screen

| Correction | Accepted behavior |
|------------|-------------------|
| White review panels | Dark panels matching Stories/Artifacts |
| Navigation | Breadcrumbs + Historian Capture / Campaign buttons |
| Wording | “Owner confidence” (not “Your private read”) |
| Download source | “Download original email as text” → `.txt` via API (not `.eml` / `file://`) |
| Thank-you | Modal with canned preview + optional personal note before send |

## Email / mailbox display

| Topic | Accepted behavior |
|-------|-------------------|
| Capture channel | UI shows `memorybox@marvinbot.net` as capture channel |
| Transport account | When Gmail API uses a different account, banner explains transport vs channel |
| Inbound replies | Auto-poll on dashboard boot and campaign open; replies appear in campaign |
