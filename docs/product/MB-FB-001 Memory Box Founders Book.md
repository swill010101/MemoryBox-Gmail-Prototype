This is a living constitution for Memory Box. It captures the philosophy, product direction, and guiding principles that should outlive any particular implementation. It is intentionally iterative and should evolve alongside the product.

---

## Core Design Principles

- Life doesn't live in folders.
- People are the anchors.
- People are the reason.
- Stories, written by a human, are first-class citizens.
- Artifacts matter because of their meaning.
- Capture should always be easier than organization.
- Trust before convenience.
- Never invent memories. Ask when uncertain.
- Never create false memories for the user. Make everything fact based and confidence biased allowing the user to guide the process.
- Memory Box preserves meaning more than media.
- Every screen should help users reconnect with a person or a story.

---

## 1. Why Memory Box Exists

People spend decades collecting photographs, videos, recipes, letters, emails, calendars, voice recordings, memorabilia, playlists, keepsakes and countless other artifacts. The problem is no longer collecting them. The problem is experiencing the story they tell.

Memory Box exists to help people rediscover their lives by connecting people, stories, places, moments, things and artifacts into a living narrative.

The amount of information is large; the ability to make sense of it is hard. Memory Box exists to help and self-organize everything around the artifacts, the stories, and the why it’s an artifact.

## 2. The Product Philosophy

Memory Box is not primarily a media manager. It is a trusted family historian.

The interface should feel conversational, warm, curious and evidence-based rather than technical.

The user asks questions. Memory Box answers with narrative supported by evidence and learns through collaboration. If Memory Box doesn’t understand the story or the question, it asks for more information pertinent to cataloguing and organizing the narrative around the artifacts.

The product must be simple to use, as it is complex underneath. It must be easy to use as well, always considering the operator’s time as important.

## 4. Version 1 Customer

Version 1 is for people who already appreciate the importance of preserving family history and who have accumulated decades of digital or physical memories.

This includes retirees, family historians, families caring for aging parents, and—more broadly—**anyone who feels overwhelmed by their artifacts**.

That may be a young family with 30,000 phone pictures, a couple preserving recipes, or someone inheriting boxes from their parents. The common problem is not age; it is the growing gap between what has been collected and the ability to rediscover it.

## 5. Trust & Ethics

Memory Box should surprise people with forgotten memories, not unwanted discoveries.

Users should control how deeply the system reasons over personal information.

Privacy, provenance, confidence and user control are product features, not afterthoughts.

Never create false memories. If inference is intended, Memory Box must give supporting evidence and confidence level. Human input is always very high confidence and outweighs AI.

## 6. Future Vision

Memory Box should eventually become a lifelong companion:

- capture memories effortlessly,
- help families tell stories,
- support memory care,
- assist funeral homes,
- preserve family history,
- and enable future generations to understand the people who came before them.

Interactive legacy experiences belong on the long-term roadmap but should never overshadow the core mission of preserving authentic stories.

## 7. What Memory Box Is Not

Memory Box is not:

- a folder manager
- a cloud storage service
- a social network
- an advertising platform
- a genealogy replacement
- software that invents memories

It complements existing systems while becoming the trusted place where meaning is preserved.
